1. Entity classification and kind membership — Recap: classify an entity as a kind. Chainer features to exercise: Plain predicate / proposition form; unary predicates for class membership; Classes and instances; STV. Constraint templates: (none)

2. Properties and attributes — Recap: assign a property/state to an entity. Chainer features to exercise: Plain predicate / proposition form; STV. Constraint templates: Use STV strength in [0.3, 0.8] only for vague or hedged property claims; otherwise unit STV is allowed.

3. Relational attributes — Recap: relate an entity to a value, role, or other entity. Chainer features to exercise: Plain predicate / proposition form; distribution-valued arguments plus STV for numeric attributes. Constraint templates: For uncertain measurements, represent the numeric value with PointMass, ParticleFromNormal, FloatDist, or NatDist inside the proposition, not as STV strength.

4. Identity and equivalence — Recap: state sameness or equality. Chainer features to exercise: Entity identity and representation; Plain predicate / proposition form. Constraint templates: If two descriptions are intended identical, downstream examples should reuse the same entity ID or assert an explicit user predicate such as (SameEntity a b); do not rely on implicit entity resolution.

5. Existence and nonexistence — Recap: assert presence or absence. Chainer features to exercise: Plain predicate / proposition form; Not; FoldAll/FoldAllValue for “no/none” counts. Constraint templates: Nonexistence examples must not model absence as missing data; use Not over a provable proposition or a count/aggregation pattern proving zero/threshold failure.

6. Definite and indefinite reference — Recap: introduce or retrieve discourse referents. Chainer features to exercise: Entity identity and representation; existential query variables; stable unique IDs. Constraint templates: Indefinite existential assertions must use a concrete fresh entity ID, while existential questions must use a query variable in the proposition.

7. Proper names and named entities — Recap: refer to named individuals/places/orgs. Chainer features to exercise: Entity identity and representation; optional user-defined Name facts. Constraint templates: Ambiguous surface names should map to distinct stable IDs plus optional Name facts; exact same ID is required for intended coreference.

8. Pronouns and coreference — Recap: resolve pronouns to antecedents. Chainer features to exercise: Entity identity and representation; pronouns/deictic entities guidance. Constraint templates: Resolved pronouns must reuse the antecedent entity ID; unresolved pronouns should use context-local placeholders or be rejected, not globally meaningful invented IDs.

9. Deixis and context-dependent reference — Recap: interpret I/you/here/now/this by context. Chainer features to exercise: Pronouns and deictic entities; Entity identity and representation. Constraint templates: Deictic referents must be concrete context IDs such as speaker_001/addressee_001 or explicit context-local placeholders.

10. Count nouns, mass nouns, and substances — Recap: distinguish countable objects and masses. Chainer features to exercise: Plain predicate / proposition form; Cardinality facts; FoldAll. Constraint templates: Exact count claims must use explicit Cardinality facts or FoldAll-derived counts, not STV strength.

11. Plurality and number — Recap: express singular/plural/group cardinality. Chainer features to exercise: Plain predicate / proposition form; FoldAll; Cardinality facts. Constraint templates: Numeral plural examples should contain either distinct entity assertions or an explicit Cardinality predicate with unit STV.

12. Collective entities and group reference — Recap: treat groups as wholes or members. Chainer features to exercise: Plain predicate / proposition form; membership predicates; And. Constraint templates: Collective readings should use a group entity; distributive readings should use member-level predicates or rules.

13. Part-whole relations — Recap: express parts, portions, members, containment. Chainer features to exercise: Plain predicate / proposition form; Implication for inherited part/member rules. Constraint templates: (none)

14. Possession and ownership — Recap: ownership/control/association. Chainer features to exercise: Plain predicate / proposition form. Constraint templates: (none)

15. Actions and events with thematic roles — Recap: encode events and roles. Chainer features to exercise: Plain predicate / proposition form; nested expressions as entities. Constraint templates: Event-role examples should use a shared event ID or nested event term for all role predicates.

16. Agent and patient relations — Recap: identify doer and affected entity. Chainer features to exercise: Plain predicate / proposition form. Constraint templates: (none)

17. Transfer and ditransitive events — Recap: giver/item/recipient events. Chainer features to exercise: Plain predicate / proposition form; nested event terms. Constraint templates: (none)

18. Instrument and means — Recap: tool or means used. Chainer features to exercise: Plain predicate / proposition form. Constraint templates: (none)

20. Experiencers and psychological states — Recap: perception/emotion/cognition states. Chainer features to exercise: Plain predicate / proposition form; STV for uncertain attitudes. Constraint templates: Hedged psychological-state claims should use STV strength in [0.3, 0.8] rather than (STV 1.0 1.0).

21. Perception events — Recap: perceiver and perceived content/object. Chainer features to exercise: Plain predicate / proposition form; nested expressions as entities. Constraint templates: (none)

Constraint templates: Numeric uncertain distance must use distribution-valued arguments; comparative proximity should use GreaterThan over distance distributions or explicit comparison predicates.

28. Paths and boundaries — Recap: through/across/into/out paths. Chainer features to exercise: Plain predicate / proposition form. Constraint templates: (none)

29. Temporal tense — Recap: locate situations in time. Chainer features to exercise: Plain predicate / proposition form; nested AtTime-style terms. Constraint templates: Tense-sensitive examples should encode time as an explicit argument or nested term; do not rely on assertion time.

34. Habitual and generic aspect — Recap: regular behaviors or characteristic truths. Chainer features to exercise: Implication; STV for tendencies. Constraint templates: Generic/habitual rules should use Implication; non-absolute tendencies should use rule STV strength in [0.5, 0.95].

35. Frequency — Recap: how often events occur. Chainer features to exercise: STV; NatDist/FloatDist; FoldAll; Compute. Constraint templates: Vague frequency claims such as often/rarely/seldom should use STV strength in [0.05, 0.9], with rarely/seldom ≤0.35 and often/frequently ≥0.6.

36. Existential quantification — Recap: at least one matching entity. Chainer features to exercise: existential query variables; concrete entity assertions. Constraint templates: Existential assertions must introduce a concrete entity ID; existential queries must use a variable inside the query proposition and variable proof slot.

37. Universal quantification — Recap: claim over all members. Chainer features to exercise: Implication; rule variables. Constraint templates: Universal “all/every/each” statements must be represented as Implication with variables in Premises and Conclusions, not as a monolithic universal predicate.

38. Cardinality and exact number — Recap: exact/min/max/approx quantities. Chainer features to exercise: Cardinality facts; FoldAll; FoldAllValue; GreaterThan; Compute. Constraint templates: Exact N must use explicit Cardinality or aggregation; “more than/at least” must use GreaterThan or Compute comparison over counts, not STV strength.

39. Generalized quantifiers — Recap: many/most/few/several/enough. Chainer features to exercise: FoldAll; FoldAllValue; Compute; GreaterThan; STV. Constraint templates: Most/majority examples should aggregate numerator and denominator counts and compare a ratio/threshold; vague many/few may use STV strength in [0.2, 0.8].

40. Proportions and percentages — Recap: fractions/ratios/shares. Chainer features to exercise: FoldAll; Compute; GreaterThan; FloatDist. Constraint templates: Percentage claims must compute or assert numeric ratios/counts; do not encode the percentage as STV strength unless it is belief uncertainty.

41. Distributive, collective, and cumulative readings — Recap: plural readings over individuals/groups/quantities. Chainer features to exercise: And; FoldAll; membership predicates. Constraint templates: Distributive “each” readings should use member-level variables/rules; collective readings should use a group entity.

42. Scope interactions — Recap: interacting quantifiers/negation/modality. Chainer features to exercise: Implication; Not; STV; rule variables. Constraint templates: Scope-sensitive examples must encode the selected reading structurally via rule variable placement, Not scope, or separate propositions.

43. Negation — Recap: deny propositions/properties/events. Chainer features to exercise: Not; STV. Constraint templates: Use Not only over a provable expression; do not use Not to mean absence of a proof unless explicitly modeled.

44. Constituent negation and contrastive negation — Recap: negate a phrase/alternative. Chainer features to exercise: Not; And. Constraint templates: Contrastive “not X but Y” should include Not(X) and positive Y as separate conjunctive propositions.

45. Negative polarity items — Recap: any/ever in negative or conditional environments. Chainer features to exercise: Not; Implication. Constraint templates: (none)

46. Modality of ability — Recap: capacity or skill. Chainer features to exercise: Plain predicate / proposition form; Implication for conditional ability; STV for uncertain ability. Constraint templates: Conditional ability must use Implication with ability preconditions in Premises.

47. Modality of possibility — Recap: may/might/could truth. Chainer features to exercise: STV. Constraint templates: Epistemic possibility claims must use STV strength in [0.1, 0.7] and not default to (STV 1.0 1.0).

48. Modality of necessity — Recap: must/required/unavoidable. Chainer features to exercise: Implication; STV. Constraint templates: Rule-like necessity/requirements should use Implication; strong epistemic necessity should use STV strength ≥0.85.

49. Permission and prohibition — Recap: allowed or forbidden actions. Chainer features to exercise: Plain predicate / proposition form; Not; Implication. Constraint templates: Prohibition should be represented with a forbidden/prohibited predicate or Not over permission; conditional permission should use Implication.

50. Obligation and advice — Recap: duties/recommendations/norms. Chainer features to exercise: Plain predicate / proposition form; Implication; STV. Constraint templates: Advice/should claims should use STV confidence or strength below 1.0 when weaker than obligation; conditional duties use Implication.

51. Causation — Recap: cause brings about effect. Chainer features to exercise: Implication; Premises/Conclusions. Constraint templates: General causal laws should use Implication from cause-condition premises to effect conclusions.

52. Purpose and intention — Recap: goal motivating action. Chainer features to exercise: Plain predicate / proposition form; Implication for means-end rules. Constraint templates: (none)

53. Result and consequence — Recap: outcome produced by event/state. Chainer features to exercise: Implication; multi-premise rules. Constraint templates: Consequence patterns should use Implication when expressed as a general dependency.

54. Comparison of degree — Recap: compare scale values. Chainer features to exercise: GreaterThan; distribution-valued arguments; LikelierThan for likelihood comparisons. Constraint templates: Numeric/degree comparisons should use GreaterThan over values/distributions or explicit comparative facts; uncertain measurements must use distributions.

55. Equality and similarity — Recap: equal values or resemblance. Chainer features to exercise: Plain predicate / proposition form; Compute for equality checks. Constraint templates: (none)

56. Superlatives and extremes — Recap: maximal/minimal member. Chainer features to exercise: FoldAll; GreaterThan; Compute. Constraint templates: Superlative examples should compare candidates via aggregation or pairwise GreaterThan rather than asserting only a bare label, when proof of maximality is expected.

57. Ordinal relations and ranking — Recap: first/second/next/ranked order. Chainer features to exercise: Plain predicate / proposition form; Compute for successor/order. Constraint templates: Numeric rank succession should use Compute where deriving next/previous ranks.

58. Conjunction — Recap: combine clauses/entities/properties. Chainer features to exercise: And; multiple Premises. Constraint templates: Rule antecedent conjunctions should be separate Premises or explicit And, not fused monolithic predicates.

59. Disjunction and alternatives — Recap: alternatives or choices. Chainer features to exercise: Or. Constraint templates: Inclusive-or examples should use Or; exclusive-or requires additional Not/constraint predicates because Or alone is not exclusive.

62. Counterfactual conditionals — Recap: remote/unreal hypotheses. Chainer features to exercise: Implication; STV. Constraint templates: Counterfactual examples should not assert the antecedent as true; if encoded as a rule, use STV confidence <1.0 or separate hypothetical-context predicates.
